## 方法取舍

种子 42 的阶段结果来自同一条按 60 轮设定学习率的训练轨迹。阶段最佳权重按已完成轮次内的原图 AUROC 选取。

| 预算 | 原图最佳权重的 TTA 准确率 / AUROC | JPEG Q75 TTA 准确率 / AUROC |
|---:|---:|---:|
| 12 | 89.62% / 0.9637 | 89.25% / 0.9608 |
| 30 | 93.94% / 0.9825 | 93.06% / 0.9797 |
| 60 | 94.69% / 0.9845 | 93.75% / 0.9815 |

第 12 轮同轮次配对评估中，EMA 使原图和 JPEG 的 TTA 准确率分别变化 +2.31 和 +2.56 个百分点。第 30 轮和第 60 轮同轮次的 EMA 对照也已保存。原尺度裁剪、像素残差和 JPEG 训练增强按组合评估。

训练与验证保留解码图像的原有像素网格，短边不足 320 的图像用反射填充。数据中的图像尺寸和历史压缩格式仍可能影响结果。

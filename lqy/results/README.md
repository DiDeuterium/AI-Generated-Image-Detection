# 成员 A · 经典 CNN 实验结果

按固定划分训练 6,400 张、验证 1,600 张。两套 CNN 初筛、三个种子复跑与一组 JPEG 增强共 180 轮。记录了 18,000 次实际参数更新，FP16 溢出跳过 0 次。支撑材料见[逐轮日志](epochs/)与[初筛图](baseline_comparison.pdf)。

## 两套 CNN 的对比

ResNet-18 按原图 AUROC 胜出。MobileNetV2 的参数量少 80.1%，在该设备上每轮训练耗时少 16.6%。其原图和 JPEG 准确率分别低 0.75 和 1.56 个百分点。ResNet-18 和 MobileNetV2 的训练分配内存峰值分别为 599 和 1268 MiB。

在 ResNet-18 的配对种子 42 实验中，JPEG 增强使原图 AUROC 变化 -0.0008，使 JPEG AUROC 变化 +0.0011。JPEG 评估衡量对统一 Q75 再编码的敏感度。

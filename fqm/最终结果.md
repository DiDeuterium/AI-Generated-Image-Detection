# fqm · 最终结果（原尺度裁剪 320 + 60 epoch + EMA）

配置来自 [调优记录](调优记录.md) 第三轮的最优项，随机种子 42 / 17 / 43 / 97 各训练一次；
每个 checkpoint 额外做五裁剪 + 水平翻转的 TTA（`fqm/evaluate_tta.py`）。
所有模型从随机初始化训练，未加载任何预训练权重；固定划分与统一 JPEG 评测协议不变。

## 配置

| 项目 | 取值 |
| --- | --- |
| 模型 | EfficientViM-M1，二分类头，参数量 5.717M |
| 输入 | 原尺度裁剪（仅在短边不足时上采样），裁剪 320×320，水平翻转 p=0.5 |
| 优化 | AdamW，lr 0.0003（前 200 步 3e-6→0.0003，其余余弦到 3e-06），wd 0.05，label smoothing 0.05 |
| 批量与预算 | 微批量 32 × 累积 2 = 有效批量 64，60 epoch × 100 次更新 = 6000 次 |
| 精度 / EMA | FP16 AMP + GradScaler；EMA decay 0.999 |
| 选模 | 原图验证 AUROC 最高的 epoch（EMA 权重） |
